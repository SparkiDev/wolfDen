# wolfMKA — Requirements & Traceability Matrix

This document traces each wolfMKA requirement to its source in the standards, to
the implementation that satisfies it, and to the verification that demonstrates
it. It is the kind of bidirectional traceability evidence expected by IEC 61508-3
and IEC 62443-4-1, and serves as the component **security/safety requirements
specification** in that document set.

Companion documents (see [`COMPLIANCE.md`](COMPLIANCE.md) for how they fit
together and the precise "supports, not certified" scope):
[`FMEA.md`](FMEA.md) (component failure-mode analysis),
[`SECURITY.md`](SECURITY.md) (vulnerability handling), and
[`MISRA.md`](MISRA.md) (coding-standard conformance).

Standards referenced:
- **802.1X-2010** — IEEE Std 802.1X-2010 (MKA protocol, Clauses 6, 9, 11).
- **802.1AE** — IEEE Std 802.1AE-2018 (MACsec, cipher suites).
- **802.1Xbx** — IEEE Std 802.1Xbx-2014 (XPN extensions).
- **RFC 4493** — AES-CMAC. **RFC 3394** — AES Key Wrap.

Verification IDs are the test functions in `test/` (run by `make test`) and the
build/quality targets. "Review" denotes a property established by inspection.

`make test-nomalloc`, `make misra` and a valgrind run cover MKA-REQ-060..064 and

response,
the OPEN Alliance Automotive profile, peer-reset recovery, the Message Number
recency window, the MACsec-statistics and PAE-status accessors, and CA
quiescing) are exercised by `make test` in every
configuration and additionally by `make test-automotive`; see
[`OPEN-ALLIANCE.md`](OPEN-ALLIANCE.md) for the profile's requirement-by-
requirement map and its known gaps. With the
fault-injection build, `make coverage` **enforces** (fails below) 100% line,
100% decision (branch) **and** 100% **MC/DC** coverage of the core sources
(`mka_crypto.c`, `mka_kay.c`, `mka_pdu.c`, `mka_status.c`), with

them, every `.c` file in `src/`. MC/DC is the masking variant accepted
by DO-178C, measured with GCC's `-fcondition-coverage` / `gcov --conditions`.
`make coverage-configs` applies the same enforced check to each delivered
configuration. See `MCDC-AND-COVERAGE.md` for the per-configuration coverage
status.
